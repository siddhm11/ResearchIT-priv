Honest answer: no, and it shouldn't be.

What it IS
A very strong bootstrap model for your specific system. The numbers are real:

nDCG@10: 0.879 (+232% over your heuristic)
0.37ms latency, 948 KB
Trained on your actual corpus (1.6M arXiv papers, 242K real citation edges)
Why the metrics look inflated
The +232% improvement is real but misleading. The heuristic baseline is artificially weak because:

EWMA profiles are zero-filled — the heuristic's main signals (features 20-22) are all 0.0, so it's effectively just 0.40 × cosine + 0.15 × recency + 0.10 × rank_confidence. That's a crippled baseline.
LightGBM gets citation graph features the heuristic literally cannot access (candidate_num_cited_by alone accounts for 65% of model importance). Of course it wins massively.
Citation pseudo-labels ≠ real user preferences — the model learns "what would a researcher cite?" not "what would a user save in their feed?"
What state-of-the-art actually looks like
The top recommendation systems (YouTube, TikTok, Pinterest) use:

Real user interaction data (millions of clicks/saves/dwell time) — we have zero
Multi-stage reranking (retrieval → coarse ranker → fine ranker → diversity) — we have retrieval → LightGBM-1 only
Cross-encoder neural rerankers (TinyBERT, cross-attention) — we skip this
Online learning with continuous retraining on fresh data — we're one-shot
Exploration/exploitation (bandit-based diversity) — we don't have this yet
Where the real gains will come from
500+ real user interactions → retrain with features 20-30 populated → the model learns actual user preferences instead of citation proxies
Phase 8b: TinyBERT cross-encoder → LightGBM-1 narrows 1000→100 candidates, TinyBERT reranks top 100 with deep semantic understanding → LightGBM-2 combines everything
More citation data — we sampled 50K of 1.6M papers. Full corpus with a working S2 API key gives ~10-40M edges instead of 242K
Bottom line
It's the right model for where ResearchIT is today — zero users, cold start, need something better than hand-tuned weights. It's not state-of-the-art in an absolute sense, and that's fine. The value is the infrastructure: 37-feature schema, time-split eval, heuristic fallback, ready to retrain when real data arrives.
